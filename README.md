# 🛠️ C-个人-实践-仓库

> 记录从基础语法验证到系统级编程尝试的 C 语言学习之路

## 📖 关于本仓库

本仓库是我自学 C 语言的专属代码归档地。这里收录了包含基础语法验证、逻辑控制流练习以及简单的系统级编程尝试的各类脚本与笔记。旨在通过不断的代码实践来复盘 C 语言的核心特性，深入理解计算机底层运行机制。

仓库将持续更新，见证我从编写第一个 `printf` 到能够进行指针操作与内存管理的每一步成长。

## 🛠️ 涉及技术栈

- **基础核心**: 数据类型、运算符、流程控制 (if/switch/loop)
- **函数与模块化**: 函数定义、递归调用、多文件编译
- **内存与指针**: 指针运算、动态内存分配 (`malloc/free`)、数组与字符串
- **结构体与联合体**: `struct`, `union`, `enum` 的定义与使用
- **文件操作**: 标准 I/O 流处理与二进制文件读写

## 💡 学习目标

1. 熟练掌握 C 语言标准语法，养成严谨的编码习惯。
2. 彻底攻克“指针”与“内存管理”难点，理解底层原理。
3. 能够独立编写小型控制台工具，为后续学习操作系统或嵌入式打下基础。
